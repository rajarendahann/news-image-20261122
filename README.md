This repository is an entry for make.fun's daily news-image competition, summing up Sunday 22 November 2026's world news in one newspaper-front-page image. The competition page: https://make.fun/bounty/news-image-20261122

## How it works

The `main.py` script is written in Python 3.13 using only the standard library. It is deterministic and copies the repository's `entry.png` (1024x1024, drawn by `gen_image.py` with PIL) to the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, which defaults to `/output`.
